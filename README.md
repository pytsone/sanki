# Sanki

Prosta przeglądarkowa gra o pingwinie zjeżdżającym na sankach.

## Uruchomienie lokalne

Otwórz `index.html` w nowoczesnej przeglądarce. Gra nie wymaga instalowania zależności ani budowania projektu.

## Sterowanie

- Strzałki w lewo/prawo lub `A`/`D`: skręcanie.
- Przyciski ekranowe albo przeciąganie na planszy: sterowanie dotykowe.
- `Spacja` lub przycisk „Doładuj”: użycie pełnego doładowania.
- Zbieraj śnieżynki, aby zdobywać punkty i napełniać doładowanie; omijaj kamienie.
- Po zebraniu 300 punktów odblokujesz nowe sanki.

Pseudonim, najlepszy wynik i zebrane punkty są przechowywane lokalnie w przeglądarce. Ranking nie jest jeszcze połączony między graczami.

## Publikacja na GitHub Pages

W ustawieniach repozytorium wybierz **Settings → Pages**, ustaw źródło na gałąź `main` i katalog `/(root)`. Po wdrożeniu strona będzie dostępna pod adresem skonfigurowanym dla repozytorium.
